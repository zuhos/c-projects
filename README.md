## C-projects collection

This repository contains small C programs built to practice core concepts 
in C.

Folder 1 contains exercises with basic flow

Folder 2 contains exercises with arrays and string manipulations

Folder 3 contains exercises with algorithms and data structures

## How to use 

```bash
git clone https://github.com/zuhos/c-projects.git
```
```
cd c-project
```
```
gcc <program.c> -o main
```
```
Linux:
./main 

Windows:
 main.exe
```
